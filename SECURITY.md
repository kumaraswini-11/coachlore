# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it
privately through GitHub: the repository's **Security** tab, then **Report
a vulnerability**
([how private reporting works](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)).

Include what you found, where, and how to reproduce it. Coachlore is a
personal project: reports are answered on a best-effort basis, and a fix is
released as soon as it's ready.

## Supported versions

Only the current `main` branch and the site deployed from it are supported.

## Scope

In scope: this repository's code and the Coachlore site and server it
deploys. Out of scope: Pokémon Showdown, Discord, PokéAPI and the other
services Coachlore uses; please report problems in those to their owners.
